# RED MIST — Community Operating System (draft)

**Find your people. Build something real.**

RED MIST is a working community for aspiring software developers, students, idea-stage founders, entrepreneurs, designers, growth/operations builders, and mentors. Current beta is 18+.

**Operating code:** COMMIT. BUILD. PROVE. REPEAT.

## What this repository does

This public repository hosts the community's **non-personal governance and operating playbook**. The production RED MIST website/app remains in its separate codebase. WhatsApp is used for focused conversation; mission commitments, member data and evidence belong in an access-controlled source of truth, not in public GitHub.

## Operating model

- Welcome beginners: assess willingness to learn, ethical behaviour, realistic commitment and proof-of-effort, not credentials.
- The existing WhatsApp Community currently has seven groups: Announcements, SIGNAL, General, BUILD FLOOR, MISSIONS & TEAMS, HELP DESK, and BUILD TABLES / EVENTS. Roles and posts are specified in the Gate 01 activation kit.
- Monday commit, Wednesday unblock, Friday show, optional Saturday Builder Table; formal 14-day mission reviews.
- Every mission has an owner, scoped deliverable, roles, deadline, acceptance criteria and evidence.
- Current target pilot: 10–20 adult builders, 3–5 genuine missions, and at least one externally tested product.
